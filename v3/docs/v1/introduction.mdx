## API Key Usage

API keys can be obtained in the [user portal](https://beaconcha.in/user/settings) and must be included in requests either as a query string parameter or in the request header.

Example: Query String Parameter
```
curl https://beaconcha.in/api/v1/slot/1?apikey=<your_key>
```

Example: Request Header
```
curl -H 'apikey: <your_key>' https://beaconcha.in/api/v1/slot/1
```
